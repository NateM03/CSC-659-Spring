Main theme:

- Current approaches include targeted laws, agency actions, standards, and policy guidance.

- China uses a more state-driven, targeted framework.

Useful angle for HW3:
- This source is strong for feasibility and implementation discussion because it shows that AI regulation is not one simple choice; it can be targeted, risk-based, flexible, or agency-led.
